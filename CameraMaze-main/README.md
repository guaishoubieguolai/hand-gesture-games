Get through a maze without touching the wall.

## How to Play

1. Run `python game.py`
2. Use your index finger to control the frog
3. Navigate through the maze from start to end
4. Don't touch the walls or you die!
5. Complete 4 levels as fast as you can

## Requirements

- Python 3.8+
- OpenCV
- MediaPipe
- Pygame

## Install

```bash
pip install opencv-python mediapipe pygame
```
