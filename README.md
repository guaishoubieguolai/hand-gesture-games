# 手势与体感控制游戏合集

通过手势或体感控制经典游戏，无需键盘或鼠标。

## 包含项目

- **mario-handgesture-game**: Intel RealSense 摄像头手势控制超级马里奥
- **CameraMaze-main**: 手指追踪穿迷宫游戏
- **HCI-handgesture-game-main**: 手势控制经典游戏合集（马里奥、坦克大战、恐龙）
- **dancedancerepo-master**: DDR 跳舞游戏 + Kinect 体感控制
- **t-rex-runner-gh-pages**: Chrome 离线恐龙跑酷游戏

## 技术栈

- Python 3.6+
- TensorFlow
- OpenCV
- MediaPipe
- Intel RealSense SDK
- Microsoft Kinect
- Gym (强化学习环境)
