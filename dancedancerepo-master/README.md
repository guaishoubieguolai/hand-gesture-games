Dance Dance Revolution + Kinect Mashup

Created for the 2015 Ualberta ECE club 24 Hour Hackathon.

## Description

This project combines Dance Dance Revolution (DDR) with Microsoft Kinect for body motion tracking.

## Components

- **kinect/**: C# Kinect driver and calibration software
- **arduino/**: Arduino firmware for hardware interaction

## Requirements

- Microsoft Kinect for Windows
- Arduino board
- Visual Studio (for C# code)
